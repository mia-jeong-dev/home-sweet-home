# 🟣 동글이의 점프맵 어드벤처

Three.js 기반 3D 점프맵 게임. 가시 함정을 피해 5단계를 클리어하세요.

## 플레이 방법

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치 불필요.

| 조작 | 키 |
|------|----|
| 이동 | WASD / 방향키 |
| 점프 | Space |
| 카메라 | 마우스 클릭 후 드래그 |

## 게임 규칙

- 닉네임을 입력하고 게임을 시작합니다.
- 각 스테이지의 **금색 플랫폼**에 올라서면 다음 단계로 진행합니다.
- **빨간 가시**에 닿으면 HP가 깎입니다. HP 0이 되면 게임 오버.
- 스테이지 클리어 시 HP가 100으로 회복됩니다.
- 5단계를 모두 클리어하면 게임 클리어!

## 스테이지

| 스테이지 | 테마 | 난이도 |
|---------|------|--------|
| 1 | 초록 숲 | 쉬움 |
| 2 | 파란 하늘 | 보통 |
| 3 | 사막 바람 | 어려움 |
| 4 | 마법 왕국 | 매우 어려움 |
| 5 | 용암 지옥 | 지옥 |

## 점수 계산

```
점수 = 스테이지 보너스 (스테이지 × 1000)
     + HP 보너스 (잔여 HP × 5)
     + 시간 보너스 (빠를수록 높음)
```

랭킹은 브라우저 `localStorage`에 저장되며 최대 20명까지 기록됩니다.

## 기술 스택

- [Three.js](https://threejs.org/) r165 — 3D 렌더링
- 순수 HTML / CSS / JavaScript (빌드 도구 없음)
